# พจนานุกรมข้อมูล
สคีมาประกอบด้วย **97 ตาราง** และ **15 view** สร้างจากไฟล์ใน `hrm/supabase/sql/`
เอกสารนี้สร้างจากสคีมาจริงที่ลงบน PostgreSQL 16 จึงตรงกับโค้ดเสมอ

## คอลัมน์มาตรฐานที่มีเกือบทุกตาราง

| คอลัมน์ | ชนิด | ความหมาย |
|---|---|---|
| `id` | uuid | รหัสหลัก สร้างด้วย `gen_random_uuid()` |
| `org_id` | uuid | องค์กรเจ้าของข้อมูล — รากฐานของการรองรับหลายหน่วยงาน |
| `facility_id` | uuid | สถานบริการ (เฉพาะตารางที่ผูกกับสถานที่) |
| `created_at` / `updated_at` | timestamptz | เวลาสร้าง/แก้ไขล่าสุด (trigger ปรับให้อัตโนมัติ) |
| `created_by` / `updated_by` | uuid | ผู้สร้าง/ผู้แก้ไข อ้าง `app_users.id` |

## ฟังก์ชันทางธุรกิจ (RPC)

ตรรกะที่ต้องสำเร็จทั้งหมดหรือไม่สำเร็จเลย เขียนไว้ในฐานข้อมูล
เพราะ Apps Script ไม่มี transaction ข้าม HTTP request

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `fn_act_leave_request()` | อนุมัติ/ไม่อนุมัติ/ส่งกลับ พร้อมเดินสายอนุมัติทีละขั้น |
| `fn_apply_career_movement()` | ดำเนินการตามคำสั่งเลื่อน/ย้าย — ปิด assignment เดิม เปิดใหม่ |
| `fn_calc_appraisal_score()` | คำนวณคะแนนถ่วงน้ำหนักและระดับผลงาน |
| `fn_complete_separation()` | ดำเนินการพ้นสภาพ — ตรวจของค้าง ปิดสิทธิ ปรับสถานะ |
| `fn_count_leave_days()` | นับวันลาโดยตัดวันหยุดและวันหยุดตามตารางเวร |
| `fn_dashboard_summary()` | ตัวเลขสรุปสำหรับหน้าแดชบอร์ด |
| `fn_generate_leave_entitlements()` | ตั้งสิทธิวันลาประจำปีทั้งองค์กร พร้อมยกยอดลาพักผ่อน |
| `fn_headcount_trend()` | กำลังคน/เข้าใหม่/พ้นสภาพ รายเดือนย้อนหลัง |
| `fn_hire_applicant()` | บรรจุผู้สมัครเป็นบุคลากร — สร้าง employee + assignment + timeline + โอนประวัติ |
| `fn_next_document_no()` | ออกเลขที่เอกสารถัดไปแบบไม่ชนกัน |
| `fn_payroll_finalize()` | ปิดรอบและสรุปยอดรวม |
| `fn_payroll_input()` | ดึงข้อมูลตั้งต้นการคำนวณเงินเดือนของรอบหนึ่ง |
| `fn_recalc_attendance()` | คำนวณสรุปเวลา 1 คน 1 วัน จากเวลาดิบ + กะ + วันหยุด + ใบลา |
| `fn_recalc_attendance_range()` | คำนวณสรุปเวลาทั้งองค์กรในช่วงวันที่ |
| `fn_record_history()` | ประวัติการแก้ไขของระเบียนหนึ่ง จาก audit_logs |
| `fn_submit_leave_request()` | ส่งใบลา — ตรวจสิทธิ/เอกสาร/การลาซ้อน + ออกเลขที่ + เข้าสายอนุมัติ |
